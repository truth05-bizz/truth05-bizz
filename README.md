## 🔧 How to run the example projects

Each project is standalone. Typical steps:

```bash
# clone a project (example)
git clone https://github.com/truth05-bizz/DSA.git
cd DSA
# run a script example
python Hashmaps/hash.py
```

If a project has a requirements.txt, create and activate a virtual environment and install dependencies:

```bash
python -m venv venv
source venv/bin/activate  # or `venv\Scripts\activate` on Windows
pip install -r requirements.txt
```

Check each repository's README for project-specific instructions (some projects may include additional setup steps).
